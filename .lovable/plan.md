
# پلانی IbadahPro

## ١. شاشەی دەستپێک (Splash)
- ٢ چرکە لۆگۆی **IbadahPro** پیشان دەدرێت پێش ئەوەی ئەپەکە بکرێتەوە.
- لۆگۆیەکی جوان دروست دەکەم بە رەنگی زێڕین لەسەر پاشبنەمای سەرمەیی، لەگەڵ ئەنیمەیشن.

## ٢. بەشی قورئان — تایبەتمەندییە نوێیەکان
- **گەڕانی سوورەتەکان**: خانەی گەڕان لە سەرەوەی لیستی سوورەتەکان (بە ناوی عەرەبی، ئینگلیزی، یان ژمارە).
- **بوکمارک**: دوگمەیەکی ⭭ لەلای هەر سوورەت. لە `localStorage` هەڵدەگیرێت. بەشێکی تایبەت بۆ سوورەتە بوکمارککراوەکان لە سەرەوە.
- **هەڵبژاردنی قاری** (Reciter picker): دروپ داونێکی جوان لە پەڕەی سوورەتدا، ٢٨ قاری تێدا (ئەبو عەینەین شوعەیشعاع، ئەحمەد عەجەمی، ئیسلام سوبحی، ... یاسر ئەلدەوسەری).
- **لێدانی دەنگ بۆ هەر ئایەتێک**: دوگمەی ▶ لای هەر ئایەت. دەنگ لە everyayah.com دێت بەپێی قاری هەڵبژێردراو.
- **خۆکار سکڕۆڵ**: کاتێک ئایەتێک لێ دەدرێت، شاشە بەشێوەی نەرم بەرەو ئەو ئایەتە سکڕۆڵ دەکات و ئایەتەکە بە چوارچێوەی زێڕین دیار دەکرێت.
- **پێش لێدان دانی هەموو سوورەت** (Play all): دوگمەیەک لە سەرەوە، ئایەت بە ئایەت بەدوای یەکدا لێ دەدات.

## ٣. سینکی وشە بە وشە (ڕەنگی زەرد)
- بۆ سینکی وشە بە وشە، داتای کاتی وشە (word timing) پێویستە — تەنیا چەند قارییەک ئەم داتایەی هەیە لە API ی **quran.com** (وەک Mishary، Abdul Basit، Husary، Minshawi، Sudais).
- بۆ ئەو قارییانە، هەر وشەیەک کە دەنگەکە پێی دەگات، دەبێتە **زەرد**.
- بۆ قاریانی تر، تەنیا ئایەتەکە بە تەواوی هایلایت دەکرێت (نەک وشە بە وشە) — چونکە داتای کات نییە.

## ٤. کاتەکانی نوێژ بەپێی شوێن
- `navigator.geolocation` بەکار دێت بۆ وەرگرتنی شوێنی بەکارهێنەر.
- API ی `aladhan.com/v1/timings` بانگ دەکرێت بۆ کاتە ڕاستەقینەکان.
- کاتی نوێژی داهاتوو + کاتژمێری پاشەکشە (countdown) پیشان دەدرێت.

## ٥. ویردی بەیانی و ئێوارە
- بەشێکی نوێ لە تابی «زیکر» (یان تابێکی نوێ).
- ٢ تاب: **ویردی بەیانی** و **ویردی ئێوارە**.
- ویردە بەناوبانگەکان (ئایەتولکورسی، موعەوویزات، حەسبی الله، ...) بە عەرەبی + وەرگێڕانی کوردی + ژمارەی دووبارەکردنەوە + شومارەرێک بۆ هەر یەکێک.

## ٦. تابی زیکر/تەسبیح (وەکو خۆی، بەڵام جوانتر)
- هیچ گۆڕانێک لە لۆجیک، تەنیا ڕێکخستن.

## تەکنیکی (Technical)
- **هەڵبژێردراوی قاری** لە localStorage: `ibadah:reciter`.
- **بوکمارکەکان** لە localStorage: `ibadah:bookmarks` (Array<number>).
- **شوێن** لە localStorage: `ibadah:coords`.
- **APIs**:
  - `api.alquran.cloud/v1/surah` — لیستی سوورەتەکان (هەیە).
  - `api.alquran.cloud/v1/surah/{n}/editions/quran-uthmani,ku.asan` — ئایەت + تەفسیر (هەیە).
  - `everyayah.com/data/{reciter}/{surahPadded}{ayahPadded}.mp3` — دەنگی هەر ئایەت بۆ ٢٨ قاری.
  - `api.quran.com/api/v4/recitations/{id}/by_ayah/{key}` — کاتی وشە بۆ قاریانی پشتیوانیکراو.
  - `api.aladhan.com/v1/timings` — کاتەکانی نوێژ.
- **پەڕگەکان**:
  - `src/lib/reciters.ts` — لیستی ٢٨ قاری + ID ی everyayah و quran.com.
  - `src/lib/adhkar.ts` — ویردی بەیانی/ئێوارە.
  - `src/components/SplashScreen.tsx` — لۆگۆ + ئەنیمەیشن.
  - `src/routes/index.tsx` — نوێ دەکرێتەوە بۆ هەموو تایبەتمەندییەکان.
  - لۆگۆیەکی نوێ لە `src/assets/logo.png` بە imagegen دروست دەکەم.
